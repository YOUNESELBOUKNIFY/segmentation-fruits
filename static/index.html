Segmentation des Fruits

À propos du projet

Ce projet a été réalisé dans un objectif éducatif. Il utilise un modèle d’IA entraîné pour la segmentation d’images de fruits. Le modèle détecte et segmente huit types de fruits : Banana, Grapes, Kiwi, Mangue, Orange, Pineapple, Pomme, Strawberry. L’objectif est de visualiser chaque fruit dans une image pour apprendre, expérimenter et comprendre le fonctionnement des modèles d’IA.

Résultats obtenus

  • mAP@50 : 92.7%
  • Precision : 88.1%
  • Recall : 86.0%
